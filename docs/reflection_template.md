## 四、心得
多子代理可讓相互獨立的任務並行，且降低不同任務的上下文干擾，但需要統一輸出格式、限制檔案寫入範圍，並由主 Agent 負責驗證與整合。最終是否提交程式，仍應由使用者確認。
