# XR 場景物件管理 API 規格

## 目的
管理 XR 場景 3D 物件的名稱、模型網址、位置、旋轉、縮放；使用 SQLite 持久化。

## 資料模型
- `id`: 系統產生之正整數識別碼
- `name`: 必填字串，長度 1–100
- `model_url`: 必填，HTTP/HTTPS 開頭，長度最多 2048
- `position`: `{x,y,z}` 三軸浮點數，範圍 -100000～100000
- `rotation`: `{x,y,z}` 三軸浮點數，範圍 -100000～100000（單位由前端約定）
- `scale`: `{x,y,z}` 三軸浮點數，必須大於 0，最多 1000
- 額外欄位禁止輸入。

## API
| 方法 | 路徑 | 功能 | 成功 | 失敗 |
|---|---|---|---|---|
| GET | `/objects` | 列出全部物件 | 200 | — |
| GET | `/objects/{id}` | 取得指定物件 | 200 | 404 |
| POST | `/objects` | 新增物件 | 201 | 422 |
| PUT | `/objects/{id}` | 完整更新物件 | 200 | 404/422 |
| DELETE | `/objects/{id}` | 刪除物件 | 204 | 404 |

## 非功能需求
使用參數化 SQL 避免 SQL 注入；pytest 至少 10 項測試；開發用途，不含帳號驗證，不宜直接公開於網際網路。
